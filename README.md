# Career Platform Backend

A FastAPI backend for an AI-powered career platform.  
It provides APIs for authentication, user management, and career-related features.

## Features

- User registration and login
- JWT-based authentication
- REST API endpoints
- Backend structure for career platform features
- Secure password handling
- API testing support

## Tech Stack

- Python
- FastAPI
- TypeScript
- JWT Authentication
- REST APIs
- Git and GitHub

## Project Purpose

This backend was created for a career platform project.  
It demonstrates backend API development, authentication, routing, and project structure using FastAPI.
